# Construye un sistema de recomendación

## Instrucciones

Dados los ejercicios de esta lección, ahora sabes cómo construir una aplicación web basada en JavaScript usando Onnx Runtime y un modelo Onnx convertido. Experimenta construyendo un nuevo sistema de recomendación utilizando datos de estas lecciones o de otras fuentes (da crédito, por favor). Podrías crear un recomendador de mascotas basado en varios atributos de personalidad, o un recomendador de géneros musicales según el estado de ánimo de una persona. ¡Sé creativo!
