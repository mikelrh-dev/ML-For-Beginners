# Juego de Parámetros

## Instrucciones

Hay muchos parámetros que se establecen por defecto al trabajar con estos clasificadores. Intellisense en VS Code puede ayudarte a explorarlos. Adopta una de las Técnicas de Clasificación de ML de esta lección y vuelve a entrenar modelos ajustando varios valores de parámetros. Construye un notebook explicando por qué algunos cambios mejoran la calidad del modelo mientras que otros la degradan. Sé detallado en tu respuesta.

## Rúbrica

| Criterio | Sobresaliente                                                                                                           | Adecuado                                               | Necesita Mejora               |
| -------- | ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------ | ----------------------------- |
|          | Se presenta un notebook con un clasificador completamente construido, sus parámetros ajustados y los cambios explicados en cuadros de texto | Un notebook está parcialmente presentado o mal explicado | Un notebook tiene errores o fallas |
