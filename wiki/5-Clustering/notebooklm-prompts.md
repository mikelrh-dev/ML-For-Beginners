# Prompts para NotebookLM — 5-Clustering

## Prompt 1: Resumen ejecutivo
```
Basándote en la documentación de clustering que te proporcioné, dame un resumen ejecutivo de 5 minutos que explique:

1. Qué es clustering y por qué es útil
2. La diferencia entre clustering y clasificación
3. Los 3 pasos principales: exploración, limpieza, aplicación de K-Means
4. Métricas clave: Silhouette Score y Elbow Method
5. Lecciones aprendidas: por qué K-Means no funcionó bien en nuestro dataset

Usa analogías simples y ejemplos del mundo real. Formato: guion para audio/podcast.
```

## Prompt 2: Generar presentación
```
Crea una presentación de 10 diapositivas sobre clustering con K-Means usando el material que te proporcioné.

Estructura sugerida:
1. Portada: "Clustering: Agrupando datos sin etiquetas"
2. ¿Qué es clustering? (con analogía de la ropa)
3. Clustering vs Clasificación
4. Ejemplos reales (mercado, anomalías, imágenes)
5. K-Means: ¿Cómo funciona? (los 5 pasos)
6. Silhouette Score: ¿Qué tan buenos son los clusters?
7. Elbow Method: ¿Cuántos clusters usar?
8. Nuestro caso práctico: música nigeriana
9. Resultados y lecciones aprendidas
10. Errores comunes y cómo evitarlos

Incluye puntos clave y analogías. Formato adecuado para presentación.
```

## Prompt 3: Quiz interactivo
```
Genera un quiz de 15 preguntas sobre clustering basado en la documentación que te proporcioné.

Incluye:
- 5 preguntas de concepto (¿qué es un centroid? ¿qué mide el silhouette score?)
- 5 preguntas de interpretación (si el score es 0.3, ¿qué significa?)
- 5 preguntas de código (¿qué hace LabelEncoder? ¿qué gráfico muestra la superposición?)

Cada pregunta con 4 opciones y la respuesta correcta al final.
```

## Prompt 4: Explicación para principiante
```
Explícame clustering como si tuviera 10 años, usando el material que te proporcioné.

Usa:
- Analogías de la vida cotidiana (ordenar ropa, mesas de restaurante, etc.)
- Ejemplos visuales (describir gráficos con palabras)
- Lenguaje simple sin jerga técnica
- PASO A PASO: primero qué es, luego por qué sirve, después cómo funciona
```

## Prompt 5: Guía de estudio
```
Crea una guía de estudio de 20 minutos para clustering con K-Means.

Estructura:
1. MINUTO 0-5: Conceptos básicos (¿qué es clustering? ¿para qué sirve?)
2. MINUTO 5-10: K-Means (cómo funciona, los 5 pasos)
3. MINUTO 10-15: Métricas (Silhouette Score, Elbow Method)
4. MINUTO 15-20: Caso práctico y lecciones aprendidas

Incluye:
- Puntos clave para memorizar
- Analogías para recordar
- Errores comunes a evitar
- Preguntas para autoevaluación
```

## Prompt 6: Audio educativo
```
Crea un guion de 10 minutos para un podcast educativo sobre clustering.

Tono: conversacional, como un profesor explicando a un amigo.
Estructura:
- Introducción: "Hoy vamos a hablar de cómo agrupar datos sin que nadie nos diga cómo"
- Ejemplo del mundo real: mercado, anomalías, recomendaciones
- K-Means explicado con la analogía de las mesas del restaurante
- Métricas: Silhouette Score como "qué tan claros están los colores"
- Nuestro caso: por qué la música nigeriana no funcionó bien
- Conclusión: "La calidad de los datos importa más que el algoritmo"

Incluye pausas marcadas y énfasis.
```

## Prompt 7: Flashcards
```
Genera 20 flashcards (frente y reverso) sobre clustering con K-Means.

Formato:
- FRENTE: Pregunta o concepto
- REVERSO: Respuesta o definición

Incluye:
- Definiciones (¿qué es un centroid?)
- Interpretaciones (¿qué significa score 0.5?)
- Comandos (¿qué hace df.describe()?)
- Errores (¿qué pasa si no escalo los datos?)
```

## Prompt 8: Comparativa de algoritmos
```
Basándote en la documentación, crea una comparativa de 4 algoritmos de clustering:

1. K-Means
2. DBSCAN
3. Gaussian Mixture
4. Hierarchical

Para cada uno incluye:
- Cómo funciona (en 2 oraciones)
- Cuándo usarlo
- Ventajas
- Desventajas
- Analogía simple

Formato: tabla comparativa + resumen ejecutivo.
```

## Notas para usar estos prompts

1. **Sube primero** los archivos wiki (README.md, 1-Visualize.md, 2-K-Means.md, glossary.md)

3. **Personaliza** si es necesario (ajusta duración, número de preguntas, etc.)
4. **Genera** y revisa el resultado
5. **Exporta** a formato que necesites (PDF, audio, presentación)

Los prompts están diseñados para aprovechar al máximo la estructura de los archivos wiki.
