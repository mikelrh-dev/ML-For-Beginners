# Web App - Del modelo a producción 🌐

> "Un modelo en tu laptop no cambia el mundo. Una app que usa el modelo, sí."

## ¿Qué es esta sección?

Aquí aprendes a convertir tu modelo ML en una aplicación web real.
Como pasar de la receta en papel a abrir tu propio restaurante.

## Lo que aprenderás

1. **Crear una app Flask** — Framework web mínimo
2. **Cargar tu modelo** — pickle y la magia de serializar
3. **Formularios HTML** — Recibir datos del usuario
4. **Predecir en tiempo real** — Modelo en producción

## Requisitos

- Completar la sección [2-Regression](../2-Regression/)
- Flask instalado: `pip install flask`
- Python 3.8+

## Lección

1. **1-Web-App** - Crear una app Flask con modelo ML

## Stack tecnológico

| Tecnología | Propósito |
|------------|-----------|
| **Python** | Backend y ML |
| **Flask** | Framework web |
| **HTML/CSS** | Frontend |
| **pickle** | Guardar modelo |
| **Bootstrap** | Estilos (opcional) |
