# Regresión - Prediciendo números

## ¿Qué es la regresión?

Imagina que quieres saber cuánto costará una casa. Tienes datos de 
casas anteriores: tamaño, número de habitaciones, ubicación. La 
regresión es encontrar la "fórmula mágica" que conecta esos datos 
con el precio.

## ¿Cuándo usar regresión?

| Tipo | Ejemplo | Modelo |
|------|---------|--------|
| **Lineal** | Predecir precio según tamaño | `LinearRegression` |
| **Logística** | Predecir si una fruta es roja o verde | `LogisticRegression` |

## Conceptos clave

- **Features**: Variables de entrada (tamaño, habitaciones)
- **Target**: Lo que queremos predecir (precio)
- **Modelo**: La "fórmula" que aprende de los datos
