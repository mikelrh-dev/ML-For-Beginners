# Epílogo: Aplicaciones reales del machine learning clásico

En esta sección del plan de estudios, conocerá algunas aplicaciones reales del ML clásico. Hemos recorrido internet en busca de documentos técnicos y artículos sobre aplicaciones que han utilizado estas estrategias, evitando en lo posible las redes neuronales, el deep learning y la IA. Aprenda cómo se usa el ML en sistemas empresariales, aplicaciones ecológicas, finanzas, arte y cultura, y más.
